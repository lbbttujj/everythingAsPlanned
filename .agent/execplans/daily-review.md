# Разбор незавершённых дел

## Purpose / Big Picture
Сегодня содержит только выбранные на день дела. Просроченные разовые дела ждут в свёрнутом блоке «Разобрать», записи без срока — в «Без даты».

## Progress
- [x] Изучен автоперенос и существующее хранение дат.
- [x] Изменить выборки, добавить управление датой и интерфейс разбора.
- [x] Typecheck и lint прошли; попытки production build выполнены, успешная сборка не подтверждена.

## Surprises & Discoveries
scheduled_for уже допускает null. Старый эффект повышал важность автоматически; происхождение прежней важности не сохранялось.

## Decision Log
- Decision: Не менять существующие важность и даты массово. Новые пропуски определять по дате при чтении; регулярные пропуски оставлять в истории.
  Rationale: Сохранить пользовательские данные и не создавать фоновых записей при загрузке.
  Date/Author: 2026-09-05 / Codex.

## Context and Orientation
components/dashboard.tsx управляет состоянием и сохранением, components/today-list.tsx рисует день. lib/planner-repository.ts уже сохраняет undefined scheduledFor как SQL null. LocalStorage не используется для новых состояний.

## Plan of Work
Удалить эффект автопереноса в Dashboard. Добавить выборки просроченных разовых и недатированных дел, обработчик сохранения даты. В TodayList добавить свёрнутые списки и действия: сегодня, дата, без даты, удалить. Сохранять счётчик переносов и показывать вопрос при трёх переносах.

## Concrete Steps
В F:\planner выполнить npm run typecheck, npm run lint, npm run build.

## Validation and Acceptance
Просроченное разовое дело отсутствует в текущем дне и доступно в разборе; выбор даты сохраняется после reload. Регулярные пропуски не добавляются в разбор. Без даты не отображается как сегодня. После трёх переносов виден вопрос об актуальности, важность автоматически не меняется.

## Idempotence and Recovery
Миграций и удаления данных нет. Повторное открытие не меняет записи. Ошибки сохранения показываются существующим механизмом Dashboard.

## Interfaces and Dependencies
TodayList получает reviewActions, undatedActions, todayKey и onSchedule(id, date?). Существующие поля scheduledFor и rolloverCount используются без изменения схемы.

## Outcomes & Retrospective
Реализованы разбор, выбор даты, хранение без даты и исключение регулярных пропусков. Исправлена выборка недели для недатированных дел. Typecheck и lint проходят. Production build первоначально упёрся в EPERM для .next/trace; повторная попытка вне песочницы не продвигалась и остановлена. Проверка в авторизованном браузере не проводилась. Для завершения проверки сборки повторить npm run build после освобождения .next от локального сервера.
