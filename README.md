# everythingAsPlanned
Все идёт по плану

Личный ежедневник на Next.js и React: дела на сегодня, календарь недели, «Мысли», цели и общие списки. Данные синхронизируются через аккаунт Supabase.

## Экран «Сегодня»

Группы дел, включая пустые, изначально свёрнуты в плитки по две в ряд. У каждой плитки есть иллюстрация на основе иконки и цвета группы, название и число незавершённых дел. Нажатие раскрывает группу на всю доступную ширину списка, повторное нажатие сворачивает её. Можно раскрыть несколько групп; порядок сохраняется, соседние элементы плавно перестраиваются. В раскрытой группе можно сразу добавить дело: группа назначается автоматически, без выбора в форме.

Раскладку и раскрытие анимирует Motion for React (`motion/react`). Системная настройка уменьшения движения учитывается. Цветная полоса остаётся у группы, у отдельных дел её нет. Выполнение, меню `⋯`, редактирование и разбор доступны внутри раскрытой группы. Бессрочные дела остаются в «Сегодня»; отдельной секции «Без даты» нет.

К делу можно выбрать несколько файлов (до 6 МБ каждый), в том числе добавлять их несколькими выборами. Длинные названия в интерфейсе сокращаются, исходные имена сохраняются. Скрепка на деле раскрывает все вложения; фото открывается для просмотра, другой файл скачивается.

## Экран «Мысли»

Личные группы показаны иллюстрированными плитками по две в ряд, в том же стиле, что группы дел. Короткое нажатие открывает группу; на телефоне удержание плитки позволяет перетащить её на другое место. После отпускания порядок сохраняется. На компьютере доступно перетаскивание мышью и управление клавиатурой.

## Разработка

```powershell
npm install
npm run dev
```

Открыть `http://localhost:3000`. Для проверки: `npm run lint`, `npm run build`, затем `npm run typecheck`. Перед production-сборкой остановить dev-сервер: обе команды используют `.next`. После сборки снова запустить `npm run dev`.

Текущее поведение и устройство: `docs/project-log.md`. Концепция интерфейса: `design.md`. Токены и анимация: `docs/design-system.md`. Правила разработки: `AGENTS.md`.

## Журнал изменений

В [CHANGELOG.md](CHANGELOG.md) перечислены завершённые изменения приложения с хешами коммитов, пояснениями, проверками и ограничениями. По хешу можно открыть точное изменение командой `git show <хеш>`.

После завершения каждой задачи с изменениями создаётся локальный коммит с поясняющим сообщением; запись с его хешем добавляется в журнал. Правило закреплено в `AGENTS.md`. Пуш выполняется по отдельному запросу.
